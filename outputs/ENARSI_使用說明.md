# ENARSI 隨身練習室

手機與電腦都可使用，不要求全螢幕。電腦可直接開啟離線資料夾的 `index.html`；手機使用私人網址，第一次匯入題庫包後即可獨立複習，不需要家裡電腦開機。

私人網址：https://enarsi-study-pocket.nidasen3020385382.chatgpt.site

## 第一次在手機使用

1. 將 `ENARSI_手機題庫包.enarsi.json` 傳到自己的手機，存入「檔案」或下載資料夾。檔案約 67 MB，已包含全部原題圖片。
2. 用手機瀏覽器開啟上方私人網址；若要求登入，使用建立此練習室的同一個帳號。
3. 按「匯入 ENARSI 題庫包」，選擇剛才的檔案。看到 **808 原題收錄、2 BGW 中文筆記** 就完成了。
4. 在「模擬測驗」設定題數及時間，即可作答。手機不必全螢幕，也不必與電腦在同一個 Wi-Fi。
5. 可將網頁加入主畫面。首次設定後，先關閉網路並重新開啟，確認題目與圖片能讀取，再作為外出離線備用。私人網站的登入與手機瀏覽器儲存方式可能影響離線開啟；必要時先連網登入。

題庫只匯入這個瀏覽器的本機儲存空間，沒有上傳到練習室伺服器。一般瀏覽模式與主畫面版本可能使用不同儲存空間；若加入主畫面後顯示空白題庫，再匯入一次即可。請保留原始題庫包，並定期匯出學習紀錄；清除瀏覽資料或使用無痕模式可能使紀錄無法保留。

## 閱讀 BGW 後自動收集

在電腦解壓縮 `ENARSI_電腦離線版.zip`，開啟資料夾中的 `啟動BGW複製收集器.cmd`。

1. 在 BGW 正常登入並開啟想閱讀的題目。
2. 按 **Ctrl+U** 開啟這題的網頁原始碼，再按 **Ctrl+A、Ctrl+C**。
3. 收集器顯示「已收集 A1／B1…」後，這題就整理完成。相同題目再次複製會合併更新，不會重複累計。
4. 它會儲存到同一資料夾下的 `我的收集/BGW_新增中文筆記.enarsi.json`。
5. 把這個檔案匯入練習室的「收集與備份」。要帶到手機，就把筆記包傳到手機後匯入。
6. 完成時，在收集器視窗按 **Ctrl+C** 或關閉視窗。

收集器只在視窗開著時觀察你複製的內容，只保存辨識成功的題幹、中文翻譯、選項翻譯、BGW 原文筆記與已支援的配對規則。不保存登入欄位、腳本、導覽列或瀏覽紀錄，不會自動翻頁或連線下載 BGW。

此啟動檔使用你這台 Windows 電腦既有的 Python 環境。手機不需要執行收集器；手機與電腦也可在練習室貼上原始碼，或直接匯入 `.txt`／`.html` 網頁檔。貼上後會顯示辨識結果，按「存入這題」確認。

## 測驗與閱讀

- **逐題練習**：選答案、立即核對、收藏、標記不確定，並依錯題或中文內容篩選。
- **模擬測驗**：自訂題數、時間、隨機抽題；交卷前不顯示中文筆記或答案。離開頁面仍計時；時間到會自動交卷，重新開啟時也會結算已逾時的測驗。
- **拖圖題**：有匯入配對規則的題目可「點選選項 → 點選分類標題」作答。無須精細拖曳；點已放入的項目可移回。
- **中文筆記**：保留 BGW 原文，重新排版讓手機可讀；沒有加入 AI 改寫的替代筆記。
- **跨裝置紀錄**：在原裝置匯出「學習紀錄」，另一裝置匯入後會先確認，再取代原進度。筆記採合併方式；進行中的測驗不跨裝置接續。
